# 图表目录（chart catalog）

> Phase 4 选图先查这张表。**表中 52 种图表全部真机渲染**，产物在 `docs/images/charts/`，可随时复现。
>
> **按需调用（推荐）**：只想要某一张，不必跑全部 ——
>
> ```bash
> python scripts/chart.py --list            # 按分类列出 52 种
> python scripts/chart.py --search 分布      # 关键词检索
> python scripts/chart.py 箱线图 --out out.png   # 只渲染这一张
> python scripts/chart.py --all             # 全量 + 拼版（CI/发版用）
> ```

## 0. 一句话原则

**先问「读者要回答什么问题」，再选图。** 同一个数据集能画十几种图，选错的代价是读者得出错误结论——
比「画得不好看」严重得多。下表按「问题类型」组织，不按图形名字母序。

## 2. 按问题类型选图（决策流程）

```text
读者要回答什么？
├─ 谁大谁小 ──────────────→ 比较：分组柱 / 条形(棒棒糖) / 子弹图 / 斜率图
├─ 怎么变的 ──────────────→ 趋势：折线 / 面积 / 阶梯 / 小倍数 / 迷你图
├─ 数据长什么样 ──────────→ 分布：直方+KDE / 箱线 / 小提琴 / 条带 / 山脊
├─ 两者有关吗 ────────────→ 关系：散点 / 气泡 / 相关矩阵 / 平行坐标
├─ 由什么构成 ────────────→ 构成：堆叠柱 / 树状 / 旭日 / 瀑布
├─ 流向哪里、流失多少 ────→ 流向：桑基 / 漏斗 / 和弦(ECharts)
├─ 什么时候做什么 ────────→ 过程：甘特 / 时间线 / 状态机
├─ 空间与场怎么分布 ──────→ 空间：等高线 / 相图 / 矢量场 / choropleth
├─ 结论有多确定 ──────────→ 推断：误差棒 / 置信带 / 森林图 / QQ
├─ 完成到哪一步 ──────────→ 进度：环形仪表 / 子弹图 / 华夫图
├─ 有周期性吗 ────────────→ 周期：玫瑰图 / 日历热力 / 阶梯
├─ 集合/群体怎么重叠 ─────→ 集合：韦恩图（≤3 组）/ 树状
└─ 概念之间怎么连 ────────→ 结构：网络图 / 弧线图 / Mermaid DAG
```

## 3. 分组详解与禁忌

### A 比较类

| 图 | 适合 | 不要用它 |
|---|---|---|
| 分组柱状图 | ≤4 组、2–3 个系列 | 组太多（>8）会糊；类别名长时改条形 |
| 条形图 / 棒棒糖 | 排名、标签长 | 需要精确读差异时补数值标签 |
| 斜率图 | 只有前后两期 | 三期以上改用折线 |
| 雷达图 | 维度 ≤6、量纲一致 | 维度 >6 或量纲不同会误导（面积不等于总量） |

### B 趋势类

| 图 | 适合 | 不要用它 |
|---|---|---|
| 折线图 | 连续时间序列 | x 轴非等距时间时要用日期轴，否则斜率失真 |
| 堆叠面积 | 总量 + 构成同时看 | 中间层难以比较（改用小倍数图） |
| 小倍数图 | 多组同构对比 | 组数 <3 时没必要 |

### C 分布类

| 图 | 适合 | 不要用它 |
|---|---|---|
| 直方图 + KDE | 看形状（偏态/双峰） | 分箱数随意会骗人：要注明 bin 宽 |
| 箱线图 | 摘要 + 离群 | **样本 <10 时不要用**，箱线会隐藏真实分布 |
| 小提琴图 | 形状 + 分位 | 样本很少时核密度不可靠 |
| 条带图 | 样本少、要诚实 | 样本 >200 会糊成一团 |
| 山脊图 | 多组分布并排 | 组数 >8 时重叠难读 |

### D 关系类

| 图 | 适合 | 不要用它 |
|---|---|---|
| 散点图 | 两变量相关 | 点太多时用六边形分箱或密度图 |
| 气泡图 | 三维编码 | 面积编码需 sqrt 缩放，否则视觉夸大 |
| 相关矩阵 | 多变量两两相关 | 只放相关系数不够，要标注样本量 |
| 平行坐标 | 多维权衡 | 维度 >8 时线会缠成蜘蛛网 |

### E 构成类

| 图 | 适合 | 不要用它 |
|---|---|---|
| 树状图 | 层级占比、类别多 | 需要精确比较数值时不如条形 |
| 旭日图 | 两层结构 | 层级 >3 会难读 |
| 瀑布图 | 逐步增减归因 | 只适合「始→终」有明确加减结构 |
| 饼图 / 环形 | **仅 ≤5 类且差异大** | 类别多、差异小、需要精确比较时**一律换条形** |

### F 流向类

| 图 | 适合 | 不要用它 |
|---|---|---|
| 桑基图 | 能量/资金/人群分配 | 节点过多会缠绕；注意带宽守恒 |
| 漏斗图 | 线性转化 | 非线性路径（有回退）不适用 |
| 和弦图 | 双向流量（需 ECharts/D3） | 节点 >12 时看不清 |

### G 过程类

| 图 | 适合 | 不要用它 |
|---|---|---|
| 甘特图 | 排期、并行任务 | 任务 >20 要分组折叠 |
| 状态机 / 流程图 | 状态转移、算法流程 | 有循环回边时用 Mermaid 更清楚 |

### H 空间与场

| 图 | 适合 | 不要用它 |
|---|---|---|
| 等高线 / 相图 | 势能面、参数分区、相变 | 数据稀疏时插值会造出假结构 |
| choropleth 地图 | 区域统计 | 面积大的区域视觉权重被夸大，要配数值 |

### I 统计推断

| 图 | 适合 | 不要用它 |
|---|---|---|
| 误差棒 | 均值 ± SD/SE | **必须写明是 SD 还是 SE**；SE 会显得更「精确」 |
| 森林图 | 多研究/多组效应量 | 样本极少时区间无意义 |

### J 第二批新增（v1.7.0，17 种）速查

| 图 | 什么时候用 | 不要用它 |
|---|---|---|
| 阶梯图 | 费率/档位这类分段恒定量 | 连续变化的数据（用折线） |
| 折线 + 置信带 | 趋势 + 不确定性 | 没有误差信息时不要凭空画带 |
| 迷你图矩阵 | 多指标同屏扫趋势 | 需要精确读数时（改折线） |
| 帕累托图 | 找主要矛盾（前 20% 贡献 80%） | 类别间无排序意义时 |
| 子弹图 | 实际 vs 目标 vs 分级区间 | 多系列叠加（改分组柱） |
| 环形仪表 | 单值 KPI 进度 | 多个 KPI 并列（改子弹图） |
| 华夫图 | 构成直觉（每格 1%） | 类别 >6 或需精确比较 |
| 玫瑰图 | 月度/季节周期 | 非周期数据（会误导成周期） |
| 云雨图 | 要看全貌：密度+箱线+原始点 | 组数 >4（会挤） |
| 联合分布 | 两个变量 + 各自边际 | 样本 <30 |
| 六边形分箱 | 上万点的散点密度 | 样本 <500（六边形太空） |
| QQ 图 | 判断是否正态、看尾部 | 读者不熟悉分位数概念时（配解释） |
| 森林图 | 多研究/多组效应量 | 只有一组（用误差棒） |
| 韦恩图 | 2–3 个集合的重叠 | 4 组以上（改 UpSet 或表格） |
| 弧线图 | 一维节点间的关系 | 节点 >20（改网络图/力导向） |
| 日历热力 | 按周×星期的节律 | 只看总量（改折线） |
| 矢量场 | 方向 + 强度（梯度、流场） | 只有大小没有方向 |

## 5. 反模式（画错比不画更糟）

1. **3D 饼图 / 3D 柱状**：透视会扭曲面积与高度，纯装饰性欺骗。
2. **截断 y 轴**：从非零起点开始，微小差异被放大成「暴涨」。
3. **双 Y 轴**：两条曲线的交叉点由刻度决定，是人为制造的相关。
4. **饼图超过 5 类**：人眼比较角度能力很差，换条形。
5. **彩虹色标表示有序数据**：应使用感知均匀色标（viridis 等）。
6. **只画均值不画分布**：均值会掩盖双峰与离群。
7. **不标样本量 / 单位 / 时间范围**：读者无法判断可信度。

## 6. 复现命令

```bash
python scripts/chart.py --all       # 重渲染全部 + 拼版（单张用 chart.py <名称>）
```
