# General Knowledge Tutor · 通识可视化学习导师

> 把「学一个东西」从线性阅读升级成：**先拆到底层 → 再建体系 → 配可视化 → 讲清本质 → 自检闭环**。
> 平台无关的 AI 智能体技能：Claude Code / OpenClaw / WorkBuddy / Cursor / WPS AI / Codex 等均可使用。

**面向读者：想直接用它学习的人 → 看本手册。想了解实现原理、二次开发 → 看 [TECHNICAL.md](TECHNICAL.md)（技术手册）。**

---

## 一、这是什么

`general-knowledge-tutor` 是一个**通识类学习技能**（Agent Skill）：安装后，你对 AI 说「帮我搞懂 X」，它不再给一篇普通讲解，而是走完一套固定五阶段工作流，交付一份**结构化学习包**：

| 阶段 | 产出 | 解决的问题 |
|---|---|---|
| Phase 1 第一性原理拆解 | 隐含假设清单 + 原子事实 + 推理链 | 死记结论，记不住 |
| Phase 2 体系化知识地图 | 概念依赖 DAG + 跨学科坐标 | 学完孤立、不成体系 |
| Phase 3 本质理解 | 一句话本质 + 生活类比（带失效边界） | 看懂了名词，没建立直觉 |
| Phase 4 可视化生产 | Manim 动画 / GIF 图表 / 交互 HTML | 抽象概念看不见摸不着 |
| Phase 5 结构化交付 | 学习卡（含自检题 + 学习路径） | 学完不知自己会不会 |

核心承诺：**所有可视化脚本真实运行渲染，不交付「看起来对」的伪产物；所有事实优先核验，不确定处标注「待核验」。**

## 二、安装

### Claude Code / OpenClaw（Agent Skills 标准格式）

```bash
# 克隆到用户级技能目录
git clone https://github.com/Asaceoo/general-knowledge-tutor-skills.git
cp -r general-knowledge-tutor-skills ~/.claude/skills/general-knowledge-tutor   # Claude Code
# OpenClaw 用户复制到其技能目录（如 ~/.openclaw/skills/）即可
```

安装后自动按 `SKILL.md` 的 description 触发，无需任何配置。

### WorkBuddy

将仓库内容复制到 `~/.workbuddy/skills/general-knowledge-tutor/`（保留 `SKILL.md` 与 `references/` 结构），重启会话即可。也可在对话中说「安装技能」从市场导入。

### Cursor / WPS AI 等无 Skill 机制的智能体

这类工具没有技能目录，用「规则注入」方式等效使用：

1. 复制本仓库 `SKILL.md` 全文。
2. Cursor：存为 `.cursor/rules/knowledge-tutor.mdc`（`description` 放进 frontmatter，`alwaysApply: false`）。
3. WPS AI / 其他：粘贴到「自定义指令 / 系统提示词 / 项目规则」中。
4. 使用时说「按 knowledge-tutor 技能讲讲 X」，即可触发同一套工作流。

### 可选依赖（决定动画质量上限）

| 依赖 | 作用 | 缺失时的行为 |
|---|---|---|
| Python 3.10+ + numpy + matplotlib | 图表 / GIF 动画（主力兜底） | 无 Python 时产出可复制的脚本，请用户运行 |
| manim（`pip install manim`） | 电影级动画 mp4 | 自动降级为 matplotlib GIF + SVG，并在交付中注明 |
| pyvista / vpython（可选） | 3D 科学可视化 / 物理教学仿真 | 自动降级为 mplot3d GIF 或 p5.js 动画 |
| 本机 Blender（可选） | 电影级 3D 渲染（bpy 无头渲染，无需 Manim） | 跳过，用其他 3D 层 |
| 浏览器 | 查看交互式 HTML 组件（含 ECharts/D3/p5.js/GeoGebra/Desmos 扩展组件） | — |
| pymunk / edge-tts / genanki / trimesh（可选，v1.2.0 第二批次） | 物理引擎真实模拟 / 中文语音讲解 mp3 / Anki 记忆卡 / 3D 模型单文件 HTML | 对应能力自动跳过或降级（见降级链） |

> 完整工具箱（含选型矩阵与降级链）见 `references/extended-viz.md`、`references/extended-viz-2.md`（第二批次，全部真机实测：Mermaid 文本即图、pymunk 物理模拟、edge-tts 配音、自测 HTML + Anki 记忆卡、model-viewer 3D 单文件交付）与 [TECHNICAL.md](TECHNICAL.md) §3.5–3.6。

### 安装验证（30 秒确认装好了）

对 AI 说：「用第一性原理讲讲熵」。若回复出现「隐含假设 / 原子事实 / 依赖图 / 类比失效边界」等结构化模块，且主动提出做可视化，即安装成功；若只返回一篇普通文章，说明技能未触发——检查文件路径是否为 `skills/general-knowledge-tutor/SKILL.md`。

## 三、快速上手（30 秒）

安装后直接说，不需要记任何指令格式：

- 「用第一性原理讲讲熵到底是什么」
- 「梯度下降我老是没直觉，做个动画帮我理解」
- 「系统学一下复利，给我画出来」
- 「帮我搞懂相对论，最好有 Manim 动画」
- 「我想入门宏观经济学，给我建个体系」

第一次使用会先确认三件事：**主题、目标深度（速览/精通/输出）、你的基础（零基础/有背景/专业）**。直接跳过让它猜也行——它按「体系化精通 + 有相关背景」默认处理并在开头标注。

### 交付物长什么样

**双文档交付**（精通/输出档共 2 个 md 文件；**文件名一律用中文**——如「电流」主题交付 `电流—通识可视化学习卡.md` + `电流—通俗版.md`，可视化产物同目录、相对路径引用）：

1. **主卡** `[主题]—通识可视化学习卡.md`——固定骨架：

```
一句话本质 → 第一性原理拆解 → 体系坐标（依赖图）
→ 通俗理解（类比 + 失效边界）→ 边界与反例
→ 可视化（动画/图表/交互组件）→ 学习路径 → 自检问题 → 参考来源
```

2. **通俗版** `[主题]—通俗版.md`——给「只想听懂」的场景（转发家人朋友、快速消化）：

```
一句话说人话 → 它解决什么麻烦 → 生活里的比方×2（各带「哪里不准」）
→ 一张图看懂（复用主卡）→ 3 个自问自答
```

通俗版承诺：不出现「第一性原理/原子事实」这类元词汇；术语翻译成日常词；篇幅 ≤ 主卡 40%；与主卡共用同一套核验过的事实，绝不二次加工数据。**速览档（30 秒版）只出通俗版 1 份**。

所有图片/动画以文件形式落盘（PNG/GIF/MP4/HTML），交互组件双击即可在浏览器使用。

## 四、使用实例（6 个真实场景）

### 实例 1 · 概念速览——「30 秒搞懂一个词」

> **你说**：「30 秒版搞懂『机会成本』」
> **它做**：跳过完整五阶段，只走「本质 + 类比 + 一张图 + 自检」。
> **你拿到**：
> - 一句话本质：机会成本 = 做出某选择时，**被放弃的最优替代选项的价值**（不是放弃的所有东西之和）
> - 类比：选了 A 电影就放弃了 B 电影——B 就是你的机会成本；失效边界：如果 B 本来你也不会去看，它不算
> - 一张图：两个选项的价值对比条形图（脚本真实运行）
> - 自检 1 题：「加班 2 小时赚 200 元 vs 陪家人，机会成本怎么算？」（附答案要点）

**适用**：读书遇到生词、聊天被科普卡壳，随手一问。

### 实例 2 · 体系化入门——「带我从零建一门的框架」

> **你说**：「我想入门宏观经济学，给我建个体系」
> **它做**：走完整五阶段；Phase 2 产出依赖 DAG 后，按「先学→后学」给学习路径。
> **你拿到**：
> - 概念依赖图（Mermaid）：GDP → 通胀/失业 → 货币政策/财政政策 → 经济周期，每节点标「先学/后学」
> - 跨学科坐标：利率在经济 vs 金融 vs 历史中的视角差异
> - **学习路径 6 站**：每站有「学完应能回答」的检查点问题
> - 自检 5 题
>
> **多轮用法**：之后每次说「继续第 2 站」，它按同一套五阶段深挖该站主题——体系不散。

**适用**：自开新学科、备考前建框架、判断一门学科值不值得深入。

### 实例 3 · 可视化点名——「我要看见它、摸到它」

> **你说**：「梯度下降我老是没直觉，做个动画，最好能拖滑块调学习率」
> **它做**：Phase 4 按你的点名选交互组件：损失曲面等高线 + 小球下坡动画 + 学习率滑块。
> **你拿到**：
> - GIF：小球在等高线图上按梯度下坡（学习率小=慢稳，大=震荡飞出——动画里看得一清二楚）
> - 交互 HTML：拖动 η 滑块，实时看收敛曲线变抖/发散
> - 分镜表：每一镜对应一句旁白（可拿去配音/讲给别人）
>
> **点名的说法**：「做成 3D」「要能拖滑块的」「要手绘风」「要白板讲解」都会被采纳；但 2D 能讲清时它会拒绝上 3D——这是特性，防炫技干扰理解。

**适用**：公式看懂了但没画面、需要给别人演示。

### 实例 4 · 输出准备——「我要讲给别人听」

> **你说**：「下周要给团队讲卡尔曼滤波，帮我准备能讲 20 分钟的材料」
> **它做**：深度切到「输出」档，除学习卡外补齐讲的东西。
> **你拿到**：
> - 完整学习卡（可当讲稿大纲）
> - 分镜表：按 20 分钟排版，每镜旁白≈朗读时长
> - 类比库：2 个生活类比（如「预测+修正=导航软件重算路线」），每个带失效边界（防被追问翻车）
> - **预设追问 Q&A**：听众最可能问的 3 个刁钻问题 + 回答要点

**适用**：技术分享、面试试讲、给孩子讲科普。

### 实例 5 · 跨学科对比——「同一个词，两副面孔」

> **你说**：「熵在热力学和信息论里是一回事吗？」
> **它做**：触发 Phase 2 跨学科坐标 + Phase 3 边界收口，专门做对比。
> **你拿到**：
> - 对比表：物理熵（S=k·lnΩ，微观状态数）vs 信息熵（H=−Σp·log p，不确定性度量）
> - 联结点：数学形式同构、Landauer 原理（擦 1 bit 至少耗散 kT·ln2 热量）
> - 常见误区：「熵=混乱」这种流行说法为什么不精确
> - 自检：给你一个新场景（如「文件压缩里有没有熵」），判断该用哪种熵

**适用**：辨析一词多义、打通学科壁垒、面试深挖。

### 实例 6 · 边界与反例追问——「它什么时候不对」

> **你说**：「相对论的适用边界和常见误解讲讲」
> **它做**：跳过入门介绍，直攻 Phase 3 的「边界与反例」+ 反例黑名单核对。
> **你拿到**：
> - 适用条件清单（低速回到牛顿力学、强场需要广义相对论……）
> - 误区对照表：每个误解 → 错在哪 → 正确表述（如「时间膨胀不是错觉，GPS 每天都在校正」）
> - 反例与待核验标注：有争议的表述明确标「待核验」而不糊弄

**适用**：查证朋友圈科普、深挖一知半解的概念。

## 六、使用技巧

1. **报你的基础**：「我是文科零基础」会让类比更生活化、术语密度更低；「我是专业的」会直接上公式。
2. **点名可视化形式**：「做成 3D 动画」「要可以拖动滑块调参数的」会被采纳（但 2D 能讲清时它会拒绝上 3D，这是特性不是 bug）。
3. **要速览版**：「30 秒版」只给本质 + 类比 + 一张图 + 自检。
4. **追问边界**：「这个概念的适用边界和反例」会触发专门的严谨性收口。
5. **面试/教学输出**：「我要讲给别人听」会按可讲解标准补全学习路径与自检题。
6. **链式追问优于另开会话**：同一会话内「继续」「再深一层」「举个反例」，它记得你的依赖图坐标。
7. **产物可复现**：所有图/动画的生成脚本都落盘，想改参数自己重跑即可。

## 七、常见问题（FAQ）

**Q1：没装 Manim 会怎样？**
自动走降级链：Manim mp4 → matplotlib 多帧 GIF → SVG 静态图 → 文字分步说明。每级降级都会在交付物中如实标注，不会假装是动画。

**Q2：中文乱码怎么办？**
技能内置防线：matplotlib 需在绘图前设置 `font.family`（如 Microsoft YaHei）与 `axes.unicode_minus: False`，模板中已写好。

**Q3：它会不会编造数据？**
质量约束禁止编造。事实优先核验（有联网工具则搜索交叉验证），无法核验的显式标「待核验」并给出验证路径。

**Q4：交互组件打不开？**
独立 HTML 文件双击用浏览器打开即可；其中 Three.js 3D 组件首次加载需联网（CDN），失败时页面会显示降级提示并指向静态 GIF。GeoGebra/Desmos 内嵌组件同样需联网。

**Q5：和直接问 AI「讲讲 X」的区别？**
直接问得到一篇作文（质量看运气）；本技能强制走五阶段 + 质量门控（🛑 STOP 检查点）+ 反例黑名单，输出确定性更高，且可视化产物可复现（脚本随交付落盘）。

**Q6：会上 3D 吗？什么时候用？**
会，但有门槛：仅当空间结构本身承载信息（旋转→振荡、螺旋、场、轨道）时启用。3D 分五层自动选型（mplot3d 兜底 → PyVista 质量主力 → vpython 教学 → Three.js 交互 → Blender bpy 电影级），你本机装了 Blender 就能用最高档。

**Q7：一个概念要等多久？**
速览版 1 次回复；完整学习卡含真实渲染的可视化，视环境通常 1–3 分钟（渲染占大头）。等不及可说「先出文字版，图后补」。
